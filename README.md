## What it does

A Python program that writes one complete story in exactly six words to `/output/entry.txt`:

> Buried the letter. Kept the lie.

## Run

```sh
python3 main.py
```

The program takes no input, makes no network calls, and writes the fixed story text to `/output/entry.txt`.
